# 🚀 Santander Bootcamp 2026 | AI React Front-end

Repositório dedicado aos estudos, desafios e projetos desenvolvidos durante o **Bootcamp Santander 2026 - AI React Front-end**.

## 🎯 Sobre o Bootcamp

O programa foca na criação de interfaces modernas, responsivas e orientadas ao usuário, combinando os fundamentos do desenvolvimento front-end com Inteligência Artificial.

**Principais aprendizados:**
- Fundamentos de **React 19** (JSX, componentes funcionais e hooks).
- Estruturação de projetos modernos e rápidos com **Vite**.
- Princípios de **UI/UX Design**, acessibilidade e consistência visual.
- Sistemas de theming e design responsivo.
- Integração com a **API do Gemini** para gerar orientações financeiras personalizadas no projeto final.

## 🗂️ Estrutura do Repositório

- `/desafios-de-codigo`: Resoluções dos desafios práticos de programação e raciocínio lógico.
- `/treinos-em-react`: Atividades práticas envolvendo IA generativa.
- `/projeto-final`: O projeto principal reunindo todo o aprendizado, que fará parte do portfólio.
